# Seguridad de la documentación

El repositorio es público y contiene únicamente ejemplos anonimizados.

No publicar:

- claves de preautorización o API de Headscale;
- credenciales MQTT o HTTPS;
- certificados y claves privadas;
- archivos `.env`;
- IP, dominios o identificadores reales de instalaciones;
- datos personales, tarifas o historiales de usuarios;
- información que permita operar equipos físicos.

Los ejemplos deben utilizar identificadores ficticios como `node-a`, `group-demo` y `operation-demo`.
